4. THE FOUR REQUIRED METHODS
--------------------------------------------------------------------------------
[x] Method 1: Source-Only ERM
    - Cross-entropy loss over domain-balanced source batches (24 samples).
    - Checkpoint saved and reused unchanged as Task 3 ERM baseline.
[x] Method 2: DAN (Deep Adaptation Networks - MMD Alignment)
    - Classification loss + lambda_MMD * MMD^2(F(Xs), F(Xt)) on 512-d feature.
    - lambda_MMD = 1.0.
    - Sum of 3 RBF Gaussian kernels with bandwidths 0.5, 1.0, 2.0 * median pairwise
      squared distance of the combined batch.
[x] Method 3: DANN (Domain-Adversarial Neural Networks - Adversarial GRL)
    - Binary domain discriminator attached to 512-d feature via Gradient Reversal Layer.
    - Architecture: Linear(512 -> 256) -> ReLU -> Dropout(0.5) -> Linear(256 -> 2).
    - Schedule: alpha(p) = 2 / (1 + exp(-10*p)) - 1, where p = epoch / max_epochs.
    - Loss: source class loss + domain classification loss (unit weight 1.0).
[x] Method 4: CDAN (Class-Conditional Adversarial Alignment)
    - Multilinear conditioning: g(x) = vec(f (x) p), dimension 512 * 7 = 3584.
    - Discriminator: Linear(3584 -> 256) -> ReLU -> Dropout(0.5) -> Linear(256 -> 2).
    - Same GRL schedule alpha(p) and unit weight as DANN.
    - No entropy conditioning; do NOT detach f or p.
